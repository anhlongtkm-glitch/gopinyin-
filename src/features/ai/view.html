🤖 AI sinh câu

Viết chủ đề bạn muốn học → AI tạo câu mới kèm pinyin & nghĩa tiếng Việt.
Tuỳ chọn nâng cao
🔑 Lấy API key Gemini (miễn phí) Bấm nút trên → đăng nhập tài khoản Google → bấm “Create API key” → sao chép key rồi dán vào ô “API key” phía trên. Key chỉ lưu trên máy bạn.
Cách dùng: chọn “Học gì” (Câu hoàn chỉnh / Từ vựng / Cả hai) → viết chủ đề → bấm “học ngay”. AI viết đợt đầu, rồi hỏi bạn có lưu lại không:
• 💾 Lưu lại → đặt tên → bộ nằm trong “Bộ AI đã lưu” ngay bên dưới; lần sau bấm “Học tiếp” là vào đúng chỗ bạn đang học dở.
• Không lưu → chỉ học tạm lần này, thoát ra là hết, không ghi gì vào máy.
Khi đang học, sắp hết là AI tự viết tiếp — nội dung mới được cộng dồn vào bộ đã lưu. Nội dung AI tạo ra không bao giờ lặp lại nhau trong cùng chủ đề.

Gemini (khuyên dùng): ổn định, chất lượng cao — bấm “🔑 Lấy API key Gemini (miễn phí)” để mở trang lấy key, dán key vào ô API key là dùng được. Key miễn phí, chỉ lưu trên máy bạn.
OpenRouter: dự phòng khi Gemini hết hạn mức — bấm “🔑 Lấy API key OpenRouter”, tạo key miễn phí rồi dán vào ô API key.

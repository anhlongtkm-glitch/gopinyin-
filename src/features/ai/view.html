Bài học theo ý bạn

Học bằng AI theo chủ đề của bạn

Chọn học câu hoặc từ vựng, viết yêu cầu rồi học ngay với chữ Hán, pinyin và nghĩa tiếng Việt.
Tuỳ chọn nâng cao
🔑 Lấy API key Gemini (miễn phí) Bấm nút trên → đăng nhập tài khoản Google → bấm “Create API key” → sao chép key rồi dán vào ô “API key” phía trên. Key chỉ lưu trên máy bạn.
Chọn Câu hoàn chỉnh / Từ vựng / Cả hai, viết chủ đề và bấm tạo. Bạn có thể lưu bộ để học tiếp đúng chỗ đang dở hoặc học tạm. Khi gần hết nội dung, AI tự viết tiếp theo cùng yêu cầu và tránh lặp lại các mục đã có. Dịch vụ dùng hạn mức API miễn phí của website; khi hết lượt, bạn vẫn học được nội dung đã tạo và có thể thử lại sau.
